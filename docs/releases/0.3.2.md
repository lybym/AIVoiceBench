# AIVoiceBench v0.3.2

This maintenance release makes fixed-case TTS generation visible and
recoverable in the Active Voice Test page. Earlier builds could leave the user
without feedback while the request was still running.

## Fixed

- Clicking **生成语音** immediately disables duplicate submission and shows an
  accessible live status.
- While synthesis is running, the browser polls the session and shows the
  actual number of ready phrases and elapsed time. It does not estimate or
  fabricate phrase completion.
- Completion restores the action, enables preview playback, and retains the
  session identifier needed for each preview URL.
- Failure and network paths restore the controls and show a readable error.
- The synthesis endpoint now returns the complete session snapshot and rejects
  a concurrent synthesis request for the same session.
- The test dependency used by FastAPI's HTTP test client is now explicit.

## Validation

- Software tests cover the complete synthesis-session response, concurrent
  request protection, and the browser live-progress contract.
- GitHub Release CI builds the Docker image, reloads the generated tarball,
  and runs synthetic container smoke tests. These checks make no cloud calls;
  credential-backed cloud synthesis is **未尝试** in CI.

## 已知限制

- The progress reflects only server-side TTS asset generation. It does not
  prove browser playback, microphone capture, a physical AI-device response,
  or a formal measurement result.
- Cloud ASR still needs an API Key plus `AIVOICEBENCH_AUDIO_PUT_URL`,
  `AIVOICEBENCH_AUDIO_GET_URL`, and `AIVOICEBENCH_AUDIO_HOST`. The PUT and GET
  URLs must address the same object（同一个对象）; a TTS API Key alone does not
  enable imported-recording ASR.
- The release workflow does not use cloud credentials. A credential-backed
  synthesis test is **未尝试** by CI.
- Frozen Golden Voice assets, full multi-turn controller behavior, and formal
  measurement evidence remain 尚未实现.

## Download and run

1. Download `aivoicebench-v0.3.2.tar.gz` and
   `start-aivoicebench-preview.ps1` from this release.
2. Verify `SHA256SUMS.txt`.
3. Run `./start-aivoicebench-preview.ps1` in PowerShell.
4. Open the local URL printed by the launcher.
