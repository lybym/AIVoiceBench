## 证据边界

- 软件 fixture、脚本化 Provider、合成麦克风与受控音频只证明有限的软件/契约行为，不是实体设备声学测量；本版所有 Feature PR 仅 `software_verified`。
- 失败、空 final、超时与无回答不会被包装成成功结果；证据不足时输出 `unknown`、`needs_review` 或 `insufficient_evidence`。
- 声学边界与 ASR speaker span 保持为相互独立的证据，对齐结果显式保留未匹配、冲突与未知状态。
- 角色归因只来自用户人工确认；未完成确认时 role-dependent Turns、Timeline、Metrics 与正式报告保持 `awaiting_role_review` / `insufficient_evidence`。
- Release 不包含 Secret、真实用户录音或个人报告；长期凭据只在后端通过 env/secret reference 解析。

## 云 ASR 前置条件

签名 URL 兼容路径需要同时设置 `AIVOICEBENCH_AUDIO_PUT_URL`、`AIVOICEBENCH_AUDIO_GET_URL` 与 `AIVOICEBENCH_AUDIO_HOST`；PUT 与 GET 必须指向**同一个对象**，`AIVOICEBENCH_AUDIO_HOST` 必须与两者的 hostname 一致。这些变量对本地导入与证据工作流是可选的；未配置时云转写与说话人标签不可用。

## 安装与启动

下载本 Release 的全部附件，先用 `SHA256SUMS.txt` 校验，再启动：

```powershell
.\start-aivoicebench-preview.ps1 -Port 8000
```

或手动加载：

```powershell
docker load -i .\aivoicebench-v0.6.0-rc.1.tar.gz
docker compose -f .\docker-compose.preview.yml up -d
```

访问 http://127.0.0.1:8000。预览 Compose 与启动脚本只绑定 `127.0.0.1`，且不会删除既有容器、镜像或数据卷。

## 迁移与兼容

- 本版**不需要数据迁移**：既有 Run 数据、Artifact 与报告保持可读，外置 `providers.yaml` / `storage.yaml` 与 SQLite legacy 兼容层不变。
- **行为变化（需要知悉）**：角色相关的分析现在必须在复核面完成人工角色确认后才会继续；未确认时 Run 保持 `awaiting_role_review`，这是产品约束的确定性实现，不是故障。
- **行为变化（需要知悉）**：无法计算的指标现在会带计数与原因显式说明，而不再以空值静默呈现。读取旧 Run 时可能看到此前未出现的缺口说明。

## 已知限制

- **M1 尚未通过。** `docs/prd/acceptance-status.md` 明确写明 “M1 尚未通过”：授权的真实 5–20 分钟录音、真实云 File ASR 与 speaker separation、人工标注/复核、完整 Judge/Findings 报告链与真实录音验收仍未闭环。本版不声明 `real_recording_verified`、`real_cloud_verified`、`real_device` 或 `measurement_equivalence_verified`。
- **PR #108 的 Gate 检查器只是工具，不等于 M1 通过。** 它只能证明记录内的声明摘要与本地文件一致、声明之间互相授权，不能证明某个声明样本确实是授权真实录音；区间与来源属于只能与记录自身对账的条件。
- **真实云调用与真实 TOS 路径未尝试。** 火山 Seed ASR 真实调用、speaker separation 质量与对象存储真实路径仍需独立真实验收（#22、#85）。
- **#98 的 TTS V3 WebSocket 迁移未实现。** 本次发布只包含 `main` 上已合入的 TTS 协议决策文档；对应实现位于尚未合并的 PR #109（issue #98），**不在本候选版范围内**，本版不得被读作 Active TTS 迁移已完成。
- **#85、#98、#74、#9 仍为 Open。** #74（M3 `max_turns` 计数）与 #9（M2 Frozen Golden Voice）未实现。
- **尚未实现 / 未尝试的里程碑能力。** Active Measurement 正式 Pipeline（F025）、Execution/Analysis Run 自动关联（F024）、Measurement Equivalence（F026）、Compare 与 Frozen Golden Voice（F018–F019）、Streaming ASR（M3）、受控 Free Test Agent（M3）仍为 `planned`；TEN VAD 的许可证审查未完成前不视为依赖验收完成。
- **F004–F009 仍为 `partial`。** 编排、File ASR、归属、Turn/EventTimeline 与确定性指标的必要闭环仍缺失。
- 默认部署面向可信单用户 localhost；远程访问需要另行配置认证与 TLS 终止。
- 候选版是**未合并发布分支构建的 Pre-release**，不是 `main` 发布；其 Pre-release 身份由 tag `v0.6.0-rc.1` 表达，镜像包与镜像内 tag 按应用版本号命名。
