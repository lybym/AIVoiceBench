# AIVoiceBench v0.2.0-alpha.2 — M1 录音分析预览版

> **v0.2.0-alpha.2 取代未发布的 0.2.0-alpha.1。** alpha.1 的启动脚本在 Windows PowerShell 5.1 下无法解析（UTF-8 无 BOM 且含中文，被按 ANSI 解码），因此在公开发布前作废；`v0.2.0-alpha.1` 标签保留不动，其 Draft Release 未发布。本版本的启动脚本以 UTF-8 BOM + CRLF 写入，在 Windows PowerShell 5.1 与 PowerShell 7 下均可解析。


**这是一个预览版（Pre-release），不是完整 M1 验收通过，也不是产品 MVP 完成声明。**

它交付的是"录音导入分析主链"当前已达到软件/容器验证级别的能力：把一段真实设备对话录音导入、保留可复核的证据、得到带时间戳的转写、查看说话人聚类、回放音频、查看阶段状态与报告，并可在重启后继续访问。

长期产品路线不变：**M1 录音分析 → M2 固定用例主动测试 → M3 大模型自由对话测试**。本预览版不改变长期范围，也不降低完整 M1 的验收要求。

## 2. 云 ASR 的完整前置条件（重要）

当前实现只支持**一个已核实的契约**：火山引擎录音文件识别极速版。

| 配置项 | 位置 | 取值/要求 |
| --- | --- | --- |
| API Key | Web「模型管理」写入（只写、不回显），或 `credential_env` 指向的环境变量 | 必填 |
| 协议 | 模型管理 | 必须 `volcengine_asr` |
| API 地址 | 模型管理 `base_url` | 必须为 `https://openspeech.bytedance.com/api/v3/auc/bigmodel/recognize/flash`（其他地址会被拒绝） |
| 模型 | 模型管理 `model` | 必须 `bigmodel` |
| 资源 ID | 模型管理 `resource_id` 参数 | 默认 `volc.bigasr.auc_turbo` |
| 音频发布 PUT 地址 | 环境变量 `AIVOICEBENCH_AUDIO_PUT_URL` | **必需**。一个 HTTPS 签名 PUT URL |
| 音频发布 GET 地址 | 环境变量 `AIVOICEBENCH_AUDIO_GET_URL` | **必需**。同一个对象的 HTTPS 签名 GET URL |
| 允许主机 | 环境变量 `AIVOICEBENCH_AUDIO_HOST` | **必需**。必须与上面两个 URL 的 hostname 完全一致 |

要点与限制：

- PUT 与 GET **必须指向同一个对象**，否则拒绝。
- 服务会上传标准化音频（PCM16 / 16 kHz / 单声道 WAV），随后用 GET URL 回读并校验 SHA256；回读不一致则判定发布失败。
- 音频上限：非空、≤ 30 分钟。
- 这三个签名 URL 通常需要由对象存储/网关**在外部生成**（例如预签名 URL 服务），**无法仅在网页内完成**，必须先准备好再启动容器。
- 音频发布 PUT/GET 必须 HTTPS、允许主机、443 或省略端口；不允许 HTTP，也不跟随重定向。模型管理对本地模型端点 HTTP 的许可不适用于这些音频发布地址。
- 保存配置**不等于**连通性验证，平台不会自动发起付费探测。

`docker-compose.preview.yml` 与 `start-aivoicebench-preview.ps1` 已预留这三个变量，也可用 `-e` 直接传入。

## 3. 已知限制

### 3.1 说话人分离的接口约定仍待确认

官方参数表在本环境无法取得（文档页为 JS 渲染）。因此：

- **不发送任何未经核实的请求参数**；已核实请求属性为 model_name、enable_itn、enable_punc、enable_ddc 和 show_utterances；不额外发送说话人分离开关。
- 若服务响应未包含说话人标签，diarization 阶段显示 `insufficient_evidence`，原因是"接口约定待确认，未发送未核实参数"，而不是提示你去打开一个并不确定的开关。
- 因此**不能**把"聚类可用"理解为"真实 Diarization 已验证可用"。

### 3.2 没有角色证据时保持 unknown

- 未配置语义角色归属、或未提供显式角色映射时，所有说话人角色保持 `unknown`。
- 角色相关的 turns/timeline/metrics 会明确弃权（`insufficient_evidence`），**不猜时间、不猜角色**。
- 聚类只说明"哪些片段属于同一说话人"，不代表已确认谁是测试者、谁是设备。
- 本预览版**不包含**语义角色归属处理器，因此默认不会出现机器推断的角色或由此产生的时延数值。相关内容见 4.2。

### 3.3 指标与语义

- 反馈时延、有效回答时延、新 Intent 时延、打断成功等需要语义证据的指标，在缺少语义服务时显示为 `insufficient_evidence`（这是正确行为）。
- 错误端点只输出**候选**，确认需要语义/人工证据。
- 所有指标仅是导入录音上的确定性结果，**未与人工标注对照**。

### 3.4 工程与部署

- 仅支持本机/内网单用户使用；密钥数据库为明文文件，**不要暴露到公网**，远程访问需自行加认证代理。
- 不提供 Windows EXE；交付形态是 Docker + Windows 浏览器。
- 单次分析上限 30 分钟 / 1 GiB（实现限制，不代表产品验收标准）。
- 未做长时间运行、并发与资源压力验证。

## 5. 安装与启动（Windows）

1. 下载本 Release 的三个附件：`aivoicebench-v0.2.0-alpha.2.tar.gz`、`docker-compose.preview.yml`、`start-aivoicebench-preview.ps1`（以及 `SHA256SUMS.txt`）。
2. 校验完整性（PowerShell）：

   ```powershell
   Get-FileHash .\aivoicebench-v0.2.0-alpha.2.tar.gz -Algorithm SHA256
   # 与 SHA256SUMS.txt 中的值一致
   ```

3. 一条命令启动（会 `docker load` 镜像、用独立容器名与独立数据卷启动、仅绑定本机）：

   ```powershell
   .\start-aivoicebench-preview.ps1
   ```

4. 浏览器打开 <http://127.0.0.1:8000>。

脚本不会删除任何已有容器或数据卷；端口被占用时会明确提示并给出可用的替代端口参数（`-Port 8001`）。

需要云 ASR 时，先按第 2 节准备好三个签名 URL 环境变量，再启动：

```powershell
$env:AIVOICEBENCH_AUDIO_PUT_URL = "https://<host>/<object>?<put-signature>"
$env:AIVOICEBENCH_AUDIO_GET_URL = "https://<host>/<object>?<get-signature>"
$env:AIVOICEBENCH_AUDIO_HOST    = "<host>"
.\start-aivoicebench-preview.ps1
```

随后在「模型管理」中新增 `volcengine_asr` 配置并写入 API Key。
