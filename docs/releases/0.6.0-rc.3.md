# AIVoiceBench v0.6.0-rc.3（Release Candidate · 预览版）

**本版本是 Pre-release，不是稳定发布，也不接管 `Latest` 标识。** 稳定版仍为 `v0.5.0`，目标稳定版本为 `v0.6.0`。

## 本候选版修复

- 修正 Issue #98 的火山 V3 单向 TTS：按当前官方文档发送单个无事件 `FullClientRequest`，不再先发空文本 `StartSession`。
- 修正双向 TTS 生命周期：`StartConnection → ConnectionStarted → StartSession`，关闭时发送 `FinishConnection`；解析响应中的 `connect_id` 与 `session_id`。
- 配置只接受当前文档的 `seed-tts-2.0` / `seed-icl-2.0` Resource ID；示例默认使用 `seed-tts-2.0` 和 `seed-tts-2.0-standard`。
- 真实 provider integration 已验证单向及双向短文本 MP3 合成；不包含密钥或可复用凭据。

## 已验证范围

- 本地 TTS 协议与冻结资产测试：101 项通过。
- PR #111：Windows、Ubuntu、容器与浏览器验收检查均通过。
- 该验证不等同于实体设备、正式声学 Measurement、浏览器实时 TTS streaming playback 或 LLM streaming 接线验收。

## 安装

```powershell
docker load -i .\aivoicebench-v0.6.0-rc.3.tar.gz
.\start-aivoicebench-preview.ps1 -Port 8000
```

附件包括 Docker 镜像包、Compose、启动脚本、SHA256SUMS 与本说明。使用前校验 SHA-256。

## 已知限制

- #98 仍保持 Open：Free 的浏览器流式播放、LLM token streaming 接线、turn/run stop/barge-in 上层取消编排尚未完成。
- 真实录音、真实设备及 Measurement Equivalence 验收尚未完成；不声明 `real_recording_verified` 或 `measurement_equivalence_verified`。
- Docker Release 是候选制品；不提供 Windows EXE 或制品签名。
