# AIVoiceBench v0.4.0-alpha.1

**这是一个预览版（Pre-release），不是完整 M2/M3 交付。** 本版只做一件事：把**固定用例
对话**（Active Voice Test / Fixed Case）的控制链路做到「停止真的停、超时不被当成回答、
跑完留下执行记录、出错不会悬挂」。

未配置云服务时，录音导入与分析主链仍可正常使用。

## 本版修复了什么（固定模式）

- **停止真的停止。** 点击“停止”立即停本地播放与监听、恢复按钮，**不等待后端确认**；
  被取消的播放等待（`playAudio` 的 Promise）会真正结束、定时器释放，且**只结束一次**。
  迟到的 `ended` 不会覆盖“已停止”、不会恢复监听、也不会推进下一轮。重复点击无副作用。
- **超时不再伪装成回答结束。** 无回答超时改发独立的 `observation_timeout` 事件，会话按
  显式策略 `on_no_response`（默认 `pause`，可选 `continue`）暂停或继续；该轮记为
  “未观察到回答”，**不会显示为正常回答完成**。
- **事件不会重复推进。** 每一轮都有会话内唯一的 `turn_id`；只有“正在等待观察且会话仍在
  运行”的那一轮能被推进。重复、迟到、未知轮次、缺少 `turn_id` 或已停止会话的事件统一
  记 `ignored`。
- **最小执行记录。** 每轮记录：本次会话/执行与第几句、使用的文本与音频资产（含 hash）、
  服务端发出的播放指令、浏览器报告的播放开始/结束/取消/失败、观察到的疑似语音开始/结束
  或无回答、以及推进/停止/失败的原因。写入会话目录 `execution-record.json`，可通过
  `GET /api/voice-test/sessions/{id}/execution-record` 查看或导出；内存会话消失（如后端
  重启）后仍可读取。重开一次执行会**归档**上一轮而不是抹掉失败证据。
- **异常一定退出，不会悬挂。** 音频不可用、浏览器拒绝播放、播放卡住、WebSocket 断开、
  会话失效/后端重启都会以明确原因结束、恢复按钮、提示可重新开始。后端不可达时**本地
  仍能停止**。等待上限是控制护栏，**不是产品性能 SLA**。

### 记录里的两条边界（有意为之）

1. “服务端发出播放指令”和“浏览器报告播放”是**两个独立事件**，二者都**不冒充真实声场
   onset**。
2. 浏览器 VAD 只报告**疑似回答**（`observation_basis=browser_vad_rms`）；它**不识别说话
   人身份**，也**不测量正式响应时延**。

## 已知限制

- **自由模式（LLM 驱动对话）的设备音频采集尚未接通**：浏览器的录制/上传环节在发布版中
  没有接线，因此自由模式的多轮对话**不会自动推进**。它**不是“填好凭据即可使用”**，
  需要后续版本实现采集接线与完整多轮验收。本版**未**改动这一范围。
- **不包含**：边播放边监听 / Barge-in、AEC、句中精确停顿、Frozen Golden 语音资产库、
  Compare/回归、专业 HIL 与 SPL 校准。
- **未实现**：语义角色归属（PR #54 未合并）、完整 Timeline 波形与人工修订工作台、
  自由模式完整验收。
- 浏览器验证使用的是**受控输入**（合成 TTS + 合成麦克风）；它验证的是软件与页面链路，
  **不能替代**真实云服务、扬声器、麦克风与实体设备的验收。
- 录音导入的云 ASR/说话人标签仍需要有效凭据，且本版**未尝试**任何真实云调用。
- 控制等待上限（播放开始 10 s、最长播放 180 s、无回答超时默认 30 s）是控制护栏，
  不是产品性能目标；可按会话调整 `no_response_timeout_ms`（1000–600000 ms）。
- 会话状态保存在进程内存中；容器重启后已打开的页面需要重新开始（执行记录文件仍在）。

## 云 ASR 前置条件（录音分析，与本版修复无关）

需要 API Key **加三个签名 URL 环境变量**，且三者必须同时设置：

- `AIVOICEBENCH_AUDIO_PUT_URL`
- `AIVOICEBENCH_AUDIO_GET_URL`
- `AIVOICEBENCH_AUDIO_HOST`

PUT 与 GET 必须指向**同一个对象**；HOST 必须与两者的 hostname 一致。只配置 TTS API Key
**不会**启用录音导入的云 ASR。仅配置 TTS 可让固定模式生成语音。

## 下载与启动

1. 从本 Release 下载 `aivoicebench-v0.4.0-alpha.1.tar.gz`、
   `start-aivoicebench-preview.ps1`、`docker-compose.preview.yml`、`SHA256SUMS.txt`。
2. 校验校验和：`SHA256SUMS.txt`。
3. Windows 上运行 `./start-aivoicebench-preview.ps1`（独立容器名与独立数据卷，仅绑定
   本机回环地址，不删除任何已有容器或数据卷）。
4. 打开脚本输出的本机 URL。
