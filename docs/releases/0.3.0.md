# AIVoiceBench v0.3.0 — 录音分析 + 主动语音测试

本次版本包含两条一级主流程的可用能力：

1. **录音分析**（Recording Analysis）：导入真实对话录音，保留可复核证据，得到带时间戳的转写、说话人聚类、阶段账本与报告。
2. **主动语音测试**（Active Voice Test）：平台生成语音，通过电脑扬声器播放，与实体 AI 设备对话，麦克风观察设备回答。

## 新增：主动语音测试

Web 导航新增「🎙 语音对话测试」入口，提供两种模式：

### 固定用例对话

- 输入一组测试话术，生成 TTS 语音
- 浏览器播放 → VAD 检测设备回答 → 自动播放下一句
- 支持试听、开始、随时停止
- 闭环：播放问题 → 观察设备开始回答 → 观察回答结束 → 播放下一问题

### 自由对话（大模型驱动）

- 设置测试目标、约束、最大轮次
- LLM Agent 生成测试话术 → TTS → 播放 → 麦克风采集 → ASR 转写 → LLM 决定下一轮
- Agent 能追问、切换话题、结束测试
- 设备回复是被测数据，不能改写测试目标或权限

## 已有：录音分析

- WAV/MP3/M4A 导入、原始/标准化资产与 provenance
- 阶段账本、Audio QA、能量 VAD
- 云 ASR 调用路径、时间戳转写、说话人标签展示
- 历史、详情、音频回放、报告、模型配置管理
- 失败信息与持久化

## 配置条件

### 录音分析（云 ASR）

- `volcengine_asr` 配置：API Key + 三个签名 URL 环境变量
- `AIVOICEBENCH_AUDIO_PUT_URL` / `AIVOICEBENCH_AUDIO_GET_URL` / `AIVOICEBENCH_AUDIO_HOST`
- PUT 与 GET 必须指向同一个对象

### 主动语音测试（TTS）

- `volcengine_tts` 配置：服务地址、模型、音色参数（voice）、API Key
- 在「模型管理」中添加，路由指向 tts

### 自由对话（额外需要）

- `openai_chat` 配置：LLM 服务地址、模型、API Key（路由指向 judge）
- `volcengine_asr` 配置 + 签名 URL（同上，用于设备回答转写）

## 已知限制

- **TTS 接口约定 pending**：官方参数表无法离线核实（JS 渲染），实现基于广泛文档的格式
- **VAD 为简单能量阈值**：不区分自身播放泄漏和设备回答，靠播放时暂停 VAD 缓解
- **自由模式 ASR 为近实时**：浏览器录音 → 上传 → flash ASR，非流式
- **未实现 F019 Frozen Golden Voice**：TTS 资产未冻结版本化
- **未实现 F020 高级场景**：句中停顿、Barge-in 条件触发、超时策略
- **未实测真实对话**：代码和软件验证完成，未在真实浏览器+设备+云服务环境中验证
- **实时控制不经过 ImportRun**：主动对话的实时观察用于控制，不产出正式测量证据
- **密钥库为明文**：仅本机/内网，勿暴露公网
- **单次分析上限 30 分钟 / 1 GiB**

## 下载与运行

1. 下载 `aivoicebench-v0.3.0.tar.gz` 和 `start-aivoicebench-preview.ps1`
2. 校验 SHA256（见 `SHA256SUMS.txt`）
3. 运行 `.\start-aivoicebench-preview.ps1`
4. 打开 http://127.0.0.1:8000

预览版使用独立容器名 `aivoicebench-preview` 与独立数据卷，仅绑定本机，不影响旧版本。
