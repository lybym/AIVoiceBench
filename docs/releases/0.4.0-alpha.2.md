# AIVoiceBench v0.4.0-alpha.2

**这是一个预览版（Pre-release），不是完整 M1/M2/M3 交付。** 本版把 Free Voice Test
从“整轮录音后再做 File ASR”的过渡方式升级为可审计的最小实时链路：浏览器连续采音，
经本机后端转发给 Streaming ASR，再以 final transcript 驱动 Agent 和下一轮 TTS。

本版没有完成真实云或实体设备验收。未配置云服务时，录音导入与本地分析能力仍可使用；
主动测试中的 Fixed Mode 仍只依赖 VAD 推进，不因 Streaming ASR 未配置而整体不可用。

## 本版新增与修复

- **连续采音与独立音频通道。** 浏览器使用 AudioWorklet 生成 16 kHz、mono、PCM16 音频帧，
  通过独立二进制 WebSocket 发送到后端；控制消息与音频负载分离，帧序、缺口、迟到、重复、
  背压和中断进入执行记录。
- **Streaming ASR Provider。** 新增供应商无关的会话/事件边界与火山引擎流式适配器，支持
  open、push audio、partial/final、endpoint、close/cancel，并保留脱敏调用审计。浏览器不
  持有长期凭据；Signed URL 不是 Active Voice Test 的前置条件。
- **Free Voice Test 最小闭环。** 设备回答的 partial transcript 可实时展示，final transcript
  才进入 Agent context 并生成下一轮；空 transcript 明确按“未观察到回答”处理，不伪造回答。
  `turn_file` 仍可作为显式 fallback，但 UI 和执行记录都会标注降级，不会静默切换。
- **发布前生命周期加固。** 正常结束会关闭供应商 WebSocket、音频文件与调用审计；浏览器
  断连/非法音频会取消供应商会话并释放捕获；同一轮的第二个音频连接不能覆盖活动捕获；
  重复或迟到 PCM 只计数、不重放给识别器；浏览器错误说明不回显供应商异常文本。
- **总体架构与 Roadmap。** 文档明确 Recording Analysis / Active Voice Test 两条主链、
  File ASR / Streaming ASR 两种生命周期、Control / Measurement Evidence 分离，以及 RTC、
  S2S、统一 Event Schema 和真实验收的后续边界。

## 已知限制

- **真实云 Streaming ASR 尚未验收。** 火山端点、鉴权头、二进制信封和已知错误码按官方
  文档实现并以本地协议服务验证，但真实鉴权、配额、判停、最大会话时长和延迟行为未尝试。
- **真实本地音频与实体设备尚未验收。** 浏览器测试使用受控合成麦克风和脚本化识别器；
  不能替代 Windows 真实输入/输出设备、声学回路或 AI 设备测试。
- **尚未实现**边播放边监听 / Barge-in、AEC、输入/输出设备选择 UI、句中精确停顿、
  Frozen Golden 语音资产、Streaming TTS、完整 Coverage/预算约束和统一 Event Schema。
- **未实现**完整 M1 Judge/Findings/人工修订/结论报告闭环；可选语义角色归属 PR #54
  仍未合并。Control Evidence 不能替代外部录音的 Measurement Evidence。
- 会话状态保存在进程内存中；容器重启后已打开页面需要重新开始，已落盘执行记录仍保留。
- 控制等待上限是防悬挂护栏，不是产品性能 SLA；预览版完成一次执行也不表示设备通过测试。

## 云服务配置边界

Streaming ASR 通过模型管理中的 `streaming_asr` 用途配置 API Key、Resource ID 和已核对的
服务参数；长期凭据只保存在后端。由于本版未做真实云调用，配置成功不应解读为服务验收通过。

Recording Analysis 的 File ASR 是另一条链。它仍需要 API Key **加三个签名 URL 环境变量**，
且三者必须同时设置：

- `AIVOICEBENCH_AUDIO_PUT_URL`
- `AIVOICEBENCH_AUDIO_GET_URL`
- `AIVOICEBENCH_AUDIO_HOST`

PUT 与 GET 必须指向**同一个对象**；HOST 必须与两者的 hostname 一致。只配置 Streaming ASR
或 TTS 不会启用录音导入的云 File ASR。

## 下载与启动

1. 从本 Release 下载 `aivoicebench-v0.4.0-alpha.2.tar.gz`、
   `start-aivoicebench-preview.ps1`、`docker-compose.preview.yml`、`SHA256SUMS.txt`。
2. 按 `SHA256SUMS.txt` 校验附件。
3. Windows 上运行 `./start-aivoicebench-preview.ps1`。脚本使用独立容器名和数据卷，
   只绑定本机回环地址，不删除已有容器或数据卷。
4. 打开脚本输出的本机 URL。
