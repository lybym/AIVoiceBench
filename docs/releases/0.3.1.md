# AIVoiceBench v0.3.1

This maintenance release fixes the Volcengine TTS integration used by Active
Voice Test. v0.3.0 sent an obsolete v1 request shape, so a current Volcengine
API Key could not synthesize test phrases.

## Fixed

- `volcengine_tts` now uses the V3 single-direction SSE endpoint and API-Key
  headers: `X-Api-Key`, `X-Api-Resource-Id`, and `X-Api-Request-Id`.
- The provider collects SSE audio frames, accepts only a nonempty valid WAV
  asset for browser playback, and never marks a failed request as playable.
- Model configuration requires an explicit resource ID and voice ID. No
  account-specific model, resource, voice, or credential is embedded in the
  image or source.
- Each completed or failed synthesis writes a credential-free audit containing
  V3 protocol metadata, configuration, request ID, timing, status, and output
  hash when present.

## Configure TTS

In **模型管理**, create a `volcengine_tts` profile with the current official
V3 endpoint, the resource ID and voice ID enabled in your Volcengine project,
and `format=wav`; write the API Key only into the API Key field or reference a
local environment variable. Route `tts` to that profile. The UI does not read
the key back, and reports do not include it.

## Validation

- Software tests cover the exact V3 request headers/body, multi-frame SSE
  decoding, WAV validation, configuration validation, and redacted failure
  audit behavior.
- GitHub Release CI builds the Docker image, reloads the generated tarball,
  and runs its synthetic container smoke tests. These CI checks make no cloud
  calls; credential-backed cloud synthesis is **未尝试** in CI.

## 已知限制

- This release does not itself prove a physical speaker/microphone/AI-device
  conversation. Browser audio permission, local acoustic leakage, and device
  behavior require a separate hardware test.
- Cloud ASR still needs an API Key plus `AIVOICEBENCH_AUDIO_PUT_URL`,
  `AIVOICEBENCH_AUDIO_GET_URL`, and `AIVOICEBENCH_AUDIO_HOST`. The PUT and GET
  URLs must address the same object（同一个对象）; a TTS API Key alone does not enable
  imported-recording ASR.
- The release workflow does not use cloud credentials. A credential-backed
  synthesis is tested separately after the release package is downloaded, and
  the local stored key is removed after that test.
- Frozen Golden Voice assets, full multi-turn controller behavior, and formal
  measurement evidence remain outside this patch and are 尚未实现.

## Download and run

1. Download `aivoicebench-v0.3.1.tar.gz` and
   `start-aivoicebench-preview.ps1` from this release.
2. Verify `SHA256SUMS.txt`.
3. Run `./start-aivoicebench-preview.ps1` in PowerShell.
4. Open the local URL printed by the launcher.
